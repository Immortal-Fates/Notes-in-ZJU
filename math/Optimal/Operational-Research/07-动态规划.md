# 动态规划
[TOC]

<!--more-->

## Takeaway

DP(dynamic programming) 就是系统性求解Bellman equation的方法

## Prior

Bellman principle

## Motivation

假设一个问题有 $T$ 个阶段，每个阶段有 $|\mathcal A|$ 个 action。暴力搜索所有 action sequence 的复杂度是：

$$
O(|\mathcal A|^T)
$$
这非常容易爆炸。

> [!TIP]
>
> 这是一个全局序贯优化问题 global sequential optimization problem

Bellman principle 告诉我们，不需要枚举完整路径：

$$
(a_0,a_1,\dots,a_{T-1})
$$
只需要知道每个 state 的最优 future value：

$$
V_t(s)
$$
于是原问题从“枚举所有路径”变成“求每个 state 的 value”。

如果状态空间大小是 $|\mathcal S|$，动作空间大小是 $|\mathcal A|$，有限时域 DP 的典型复杂度是：

$$
O(T|\mathcal S||\mathcal A|)
$$

## Core Mechanism

通过 **Bellman 最优化原理**分解多阶段决策：最优策略的子策略必是对应子问题最优。核心是利用**无后效性**使子问题独立优化，保证局部 ⇒ 全局最优

将一个全局优化问题拆为一个当前动作+一个同类型的未来优化问题
$$
\text{state} \to \text{transition} \to \text{value}
$$

- state: 状态设计，好的状态包含做未来决策所需的全部信息

  Markov property无后效性：

  $$
P(s_{t+1} \mid s_t, a_t, h_{t-1}) = P(s_{t+1} \mid s_t,a_t)
  $$

- Action: $a_k$
- transition: $s_{k+1} = T_k(s_k, a_k)$
- boundary: 递推起点or终点
- Value
- Computation Order

  - 逆序解法（Backward Induction）：从末阶段逆向递推，**初始状态给定时最常用**
  - 顺序解法（Forward Induction）：从起点正向递推，**终点状态给定时适用**。


| 情况                    | DP 形式                           | 常见求解                             |
| ----------------------- | --------------------------------- | ------------------------------------ |
| 离散 state，离散 action | value table                       | tabular DP                           |
| 连续 state，离散 action | value function                    | grid + interpolation / approximation |
| 离散 state，连续 action | 每个 state 解连续优化             | inner optimization                   |
| 连续 state，连续 action | functional Bellman equation / HJB | PDE / Riccati / ADP / RL             |
| 高维连续 state/action   | approximate DP                    | neural networks / sampling           |

an example: LQR

## Pros

- 降低计算复杂度
- 适合有 sequential decision structure 的问题。
- 给出的是全局最优，不是 greedy local optimum

## Cons

- 状态空间高维度容易爆炸curse of dimensionality，这时常用RL
- 需要知道状态转移模型
