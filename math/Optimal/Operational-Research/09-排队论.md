# 排队论
[TOC]

<!--more-->

## Takeaway

排队论 (Queueing Theory) 研究**随机聚散现象**——基于 birth-death process 推导系统稳态指标：

| 符号 | 含义 | 典型公式 (M/M/1) |
|------|------|-------------------|
| $L$ | 平均系统顾客数 (队长) | $\dfrac{\rho}{1-\rho}$ |
| $L_q$ | 平均排队顾客数 (排队长) | $\dfrac{\rho^2}{1-\rho}$ |
| $W$ | 平均逗留时间 | $\dfrac{1}{\mu-\lambda}$ |
| $W_q$ | 平均等待时间 | $\dfrac{\rho}{\mu-\lambda}$ |
| $\rho$ | 服务强度 (utilization) | $\dfrac{\lambda}{\mu}$ |

核心关系（对任意排队系统成立）：

$$\boxed{L = \lambda W},\quad \boxed{L_q = \lambda W_q}\quad\text{(Little's Law)}$$

---

## Motivation

排队论的目标：在给定到达与服务规律下计算性能指标，科学配置服务资源。**服务成本与等待成本之间存在 trade-off**——呼叫中心坐席、维修人员、网络带宽、收银台等均适用。

## Core Mechanism

### 排队系统要素与 Kendall 记号

**三要素**：输入过程（到达间隔分布 M/D/E_k/G，批量/单个，有限/无限源）、服务机制（台数 c、服务时间分布 M/D/E_k/G）、排队规则（FCFS/LCFS/Priority/SIRO/PS）。

Kendall 记号：

$$\boxed{A / B / c / K / m / Z}$$

| 位置 | 含义 | 常见取值 |
|------|------|---------|
| 1 | 到达间隔分布 | M (Poisson), D (定长), $E_k$ (Erlang), G (一般) |
| 2 | 服务时间分布 | 同上 |
| 3 | 并行服务台数 $c$ | 1, 2, … |
| 4 | 系统容量 $K$（含服务中） | $\infty$ 可省略 |
| 5 | 顾客源大小 $m$ | $\infty$ 可省略 |
| 6 | 排队规则 $Z$ | FCFS (default) |

**常用简化**：$M/M/1$（Poisson 到达 + 指数服务 + 单台），$M/M/c$，$M/M/1/K$（有限容量），$M/G/1$（一般服务分布）。

### M/M/1 模型

| 参数 | 含义 |
|------|------|
| $\lambda$ | 到达率，间隔 ~ $\text{Exp}(\lambda)$ |
| $\mu$ | 服务率，服务时间 ~ $\text{Exp}(\mu)$ |
| $\rho = \lambda / \mu$ | 服务强度 (traffic intensity) |

**生灭过程**：$\Delta t$ 内 $P\{\text{1 到达}\}=\lambda\Delta t$, $P\{\text{1 离开}\}=\mu\Delta t$。

**稳态平衡方程**：
$$\lambda \pi_0 = \mu \pi_1,\quad (\lambda + \mu)\pi_n = \lambda \pi_{n-1} + \mu \pi_{n+1},\; n\ge 1$$

解得 $\pi_n = \rho^n \pi_0$, $\pi_0 = 1-\rho$，要求 $\rho < 1$（否则队列爆炸）。

$\rho$ = 服务台繁忙概率，$1-\rho$ = 空闲概率；$\rho \to 1$ 时排队急剧增长。

**性能指标**：

| 指标 | 公式 |
|------|------|
| 平均队长 $L$ | $\displaystyle \frac{\rho}{1-\rho} = \frac{\lambda}{\mu - \lambda}$ |
| 平均排队长 $L_q$ | $\displaystyle \frac{\rho^2}{1-\rho}$ |
| 平均逗留时间 $W$ | $\displaystyle \frac{1}{\mu - \lambda}$ |
| 平均等待时间 $W_q$ | $\displaystyle \frac{\rho}{\mu - \lambda}$ |
| $\pi_n$ | $(1-\rho)\rho^n$ |
| 等待概率 $P(W>0)$ | $\rho$ |

**闭环关系**：$\rho \to L \to L_q \to W_q \to W \to L$（Little's Law 连接）。

### M/M/1/K 模型（有限容量）

系统容量 $K$，满时新到达被拒绝 (blocking)。

$$\pi_n = \frac{\rho^n}{\sum_{i=0}^K \rho^i},\quad L = \frac{\rho[1 - (K+1)\rho^K + K\rho^{K+1}]}{(1-\rho)(1-\rho^{K+1})}$$

$$\lambda_{\text{eff}} = \lambda(1 - \pi_K),\quad W = \frac{L}{\lambda_{\text{eff}}}$$

### M/M/c 模型（多服务台）

$c$ 台并联，总能力 $c\mu$，稳态条件 $\rho = \lambda/(c\mu) < 1$。

**Erlang-C 公式**（所有服务台均繁忙的概率）：
$$P(W>0) = \frac{(c\rho)^c}{c!(1-\rho)}\bigg/\left[\sum_{n=0}^{c-1}\frac{(c\rho)^n}{n!} + \frac{(c\rho)^c}{c!(1-\rho)}\right]$$

$$L_q = P(W>0)\frac{\rho}{1-\rho},\quad L = L_q + c\rho,\quad W = L/\lambda,\quad W_q = L_q/\lambda$$

### M/M/∞ 模型

无排队，立即服务。$L = \rho,\; W = 1/\mu,\; \pi_n = \rho^n e^{-\rho}/n!$。

## Key Formulas

### Little's Law

$$\boxed{L = \lambda W},\quad \boxed{L_q = \lambda W_q}$$

对任意稳态排队系统成立，$\lambda$ 为有效到达率。

### PASTA

**Poisson Arrivals See Time Averages** — 若到达为 Poisson 过程，到达顾客看到状态 $n$ 的概率等于 $\pi_n$。

### 各模型指标速查表

| 模型 | 稳态条件 | $L$ | $L_q$ | $W$ | $W_q$ |
|------|----------|-----|-------|-----|-------|
| M/M/1 | $\rho<1$ | $\dfrac{\rho}{1-\rho}$ | $\dfrac{\rho^2}{1-\rho}$ | $\dfrac{1}{\mu-\lambda}$ | $\dfrac{\rho}{\mu-\lambda}$ |
| M/M/1/K | 任意 $\rho$ | $\dfrac{\rho[1-(K+1)\rho^K+K\rho^{K+1}]}{(1-\rho)(1-\rho^{K+1})}$ | $L-\rho(1-\pi_K)$ | $\dfrac{L}{\lambda(1-\pi_K)}$ | $W-\dfrac{1}{\mu}$ |
| M/M/c | $\rho<1$ | $L_q+c\rho$ | $P(W>0)\dfrac{\rho}{1-\rho}$ | $\dfrac{L}{\lambda}$ | $\dfrac{L_q}{\lambda}$ |
| M/M/∞ | 任意 $\rho$ | $\rho$ | $0$ | $\dfrac{1}{\mu}$ | $0$ |
| M/G/1 | $\rho<1$ | $\rho + \dfrac{\rho^2(1+C_s^2)}{2(1-\rho)}$ | $\dfrac{\rho^2(1+C_s^2)}{2(1-\rho)}$ | $\dfrac{L}{\lambda}$ | $\dfrac{L_q}{\lambda}$ |

> M/G/1 使用 **Pollaczek–Khinchine (P-K) 公式**，$C_s = \sigma_s / \bar{S}$ 为服务时间变异系数。

### 经济分析

典型成本 (M/M/1)：$\displaystyle \min_{\mu} C(\mu) = c_s \mu + c_w L$，代入 $L = \lambda/(\mu-\lambda)$ 可解最优服务率 $\mu^*$。M/M/c 则优化整数 $c$。

## Pros / Cons

| Pros | Cons |
|------|------|
| ✅ Poisson 到达 + 指数服务高度可处理（闭式解） | ❌ 现实到达常非 Poisson（定长、bursty） |
| ✅ Little's Law 普适直观 | ❌ 指数分布无记忆性只是近似 |
| ✅ M/M/c 直接指导资源规划 | ❌ 复杂系统（priority queue, network of queues）无闭式解 |
| ✅ 定量分析 trade-off 框架 | ❌ 仿真往往是复杂系统的唯一手段 |
