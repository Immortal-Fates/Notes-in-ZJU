## Season 1

### 本福特定律

- 现象：为什么生活中的很多数字更常以 1 开头，而不是平均地以 1 到 9 开头？

因为世界不止是加法的还是乘法的，它的关键不在于某个数字“偏爱”1，而在于真实世界中很多量是按倍数增长、缩小或跨越多个数量级的。1 到 2 是翻倍，9 到 10 只增加约 11%。如果把数字放在对数刻度上看，1 到 2、2 到 4、4 到 8 这样的“倍数距离”才更接近我们要观察的结构

> [!TIP]
>
> 本福特定律不是所有数据都适用。它更适合自然生成、跨数量级、没有人为限定上下界的数据

### 庞加莱猜想

拓扑学topology：研究空间的基本特性。几何学关心长度、角度和面积；拓扑学更关心连接方式、洞的数量和整体结构。只要不撕裂、不粘合，一个形状可以连续变形为另一个形状，它们就被认为拓扑等价。将拓扑学中的形状称为流形manifold

> [!TIP]
>
> 这里可以理解而为一个拓扑套索，去缩紧，但是甜甜圈却无所缩成一个点，因此其与球形不同胚

庞加莱猜想追问的是三维空间中“球面”究竟如何被识别：任一单连通、紧致的、无边界的、三维流形都同胚于三维球面

在二维世界中，我们知道球面有一个重要性质：任何闭合圈都可以收缩成一个点。庞加莱猜想把这个直觉推广到三维流形：如果一个封闭三维空间中每条闭合曲线都能收缩成一点，那么它是否本质上就是三维球面？

> [!NOTE]
>
> 我见到的球都是二维球面（比如足球），因为将其无限放大，我在上面相当于在一个二维平面上移动，因此有些球面被画为平面球形图（比如世界地图），
>
> - 其是没有边界的，因为左右边界是虚拟的，从左边走出去就会从右边走进来。因此称为无边界without boundary
> - 紧致的compact:不能无限扩大，可以放在一个更大的球面上
> - 单连通：拓扑套索可以收紧到一点

| 概念     | 说明                                                     |
| -------- | -------------------------------------------------------- |
| 拓扑学   | 研究连续变形下不变性质的数学分支                         |
| 同胚     | 两个空间可通过连续变形互相转化                           |
| 流形     | 局部看像普通欧氏空间的空间                               |
| 闭合曲线 | 起点和终点相同的曲线                                     |
| 三维球面 | 四维空间中到原点距离固定的点集，可视作三维空间的球面类比 |

后面证明庞加莱猜想是正确的

### 走向并超越无限

“无限也有大小”：自然数、偶数、分数、实数都可以是无限集合，但它们的无限程度并不完全一样

我们通常把无限理解为“数不完”。但数学家康托尔发现，数不完并不意味着所有无限都一样大。比较无限集合大小的关键方法不是数完它们，而是看能否建立**一一对应**。

自然数和偶数看似一个多一个少，但可以这样配对：

$$
1\leftrightarrow 2,\quad 2\leftrightarrow 4,\quad 3\leftrightarrow 6,\dots
$$

每个自然数对应一个偶数，每个偶数也对应一个自然数，因此它们在集合论意义上“一样多”。

但实数集合比自然数集合更大，因为康托尔对角线证明显示：任何试图列出所有实数的清单都会漏掉某些实数。

> [!NOTE]
>
> 如果有人声称已经列出了 0 到 1 之间所有小数，我们可以沿列表对角线逐位修改，构造一个与列表中每个数至少一位不同的新数。这个新数必然不在原列表中。

| 概念       | 说明                         |
| ---------- | ---------------------------- |
| 可数无限   | 能与自然数建立一一对应的无限 |
| 不可数无限 | 无法用自然数逐个编号的无限   |
| 一一对应   | 两个集合元素互相配对且无遗漏 |
| 对角线论证 | 康托尔证明实数不可数的方法   |
| 势         | 集合大小的抽象度量           |

这个无限的阶级用势来表示

### 囚徒困境

Game Theory博弈论

囚徒困境：囚徒困境描述两个嫌疑人被分开审讯。每个人都可以选择沉默或背叛。如果两人都沉默，结果较好；如果一人背叛而另一人沉默，背叛者获利、沉默者受重罚；如果两人都背叛，双方都受损。

从个人角度看，无论对方怎么选，背叛似乎都更安全，于是两人都倾向于背叛。但这会导致双方结果比共同合作更差。这就是博弈论中非常重要的张力：**局部最优不等于整体最优**。

| 概念     | 说明                                     |
| -------- | ---------------------------------------- |
| 博弈论   | 研究多个决策者相互影响时如何选择         |
| 囚徒困境 | 合作有利于整体，但背叛对个体有诱惑       |
| 占优策略 | 无论对方如何选择都更优的策略             |
| 纳什均衡 | 没有人能单方面改变策略获得更好结果的状态 |
| 重复博弈 | 同一博弈重复发生，历史行为会影响未来选择 |

### 哥德尔定理

哥德尔不完备定理：在足够强大的形式数学系统中，总会存在一些为真却无法在系统内部被证明的命题。

数学曾经有一个宏大梦想：把所有数学真理建立在一套严格公理和推理规则之上，只要命题为真，就能被证明；只要命题为假，就能被反驳。哥德尔的不完备定理打破了这个梦想。

哥德尔构造了一种能谈论自身的数学语句。它大意上类似：“这个命题不能在本系统中被证明。”如果系统证明了它，就会矛盾；如果系统不能证明它，而系统又是一致的，那么它就是真的但不可证明。

我们先来了解一些概念

| 概念       | 说明                                       |
| ---------- | ------------------------------------------ |
| 形式系统   | 由公理和推理规则组成的符号系统             |
| 一致性     | 系统不会同时证明一个命题及其反命题         |
| 完备性     | 系统中每个真命题都可被证明                 |
| 自指       | 命题谈论自身                               |
| 不完备定理 | 足够强且一致的系统不可能同时证明所有真命题 |

一个数学系统（形式系统）包含三样东西：

```
1. 公理（起点）
2. 推理规则（怎么推）
3. 定理（推出来的结论）
```

例如：自然数系统（1,2,3,...），算术（加法、乘法），逻辑系统（如果…那么…）

- 第一不完备定理：在任何“足够强”的系统中：一定存在一个命题**：**

  - 它是真的

  - 但在系统内部无法被证明

  > [!tip]
  >
  > 直觉理解：
  >
  > 哥德尔构造了一个“自我指涉”的命题：
  >
  > ```
  > “这句话无法被证明”
  > ```
  >
  > 这句话很像“说谎者悖论”，但更严谨

  因此有些“真命题”，永远无法在系统里证明。系统不完备

- 第二不完备定理：一个系统不能在自身内部证明：“我自己是没有矛盾的”

  就像：

  ```
  一个人不能完全证明自己永远不会犯错
  ```

  必须依赖更高层的系统。

下面我们来看看哥德尔定理的证明

哥德尔编码构造过程

- 给每个形式符号编号

   例如：

   - `0 → 1`
   - `S → 2`
   - `+ → 3`
   - `× → 4`
   - `= → 5`
   - `( → 6`
   - `) → 7`
   - `x → 8`
   - `∀ → 9`

- 把公式转换成数字序列

   例如公式：

   ```text
   ∀x (x + 0 = x)
   ```

   可以转换成：

   ```
   9, 8, 6, 8, 3, 1, 5, 8, 7
   ```

- 用质数幂编码数字序列

  如果一个序列是：

  ```
  a₁, a₂, a₃, ..., aₙ
  ```

  则编码为：

  ```
  N = 2^a₁ × 3^a₂ × 5^a₃ × ... × pₙ^aₙ
  ```

- 利用质因数分解的唯一性

  因为每个整数的质因数分解唯一，所以：

  ```
  一个整数 ↔ 一个唯一的符号序列
  ```

  这意味着数学公式可以被唯一地表示为自然数。

- 把证明过程也编码成数字

  一个证明由多行公式组成：

  ```
  第 1 行公式
  第 2 行公式
  第 3 行公式
  ...
  ```

  每一行公式都有自己的哥德尔数。

  因此，整个证明也可以看作一个公式序列，并再次编码成一个自然数。

- 把“可证明性”转化为数论性质

  原本的说法：

  ```
  命题 A 是可证明的
  ```

  可以转化为：

  ```
  存在一个自然数 n，使得 n 是命题 A 的合法证明编码
  ```

  于是，“证明”变成了关于自然数的性质。

- 让数学系统能够谈论自身

  由于公式、证明、推理过程都已经变成了数字，数学系统就可以在内部表达：

  ```
  某个数字是不是合法公式
  某个数字是不是合法证明
  某个数字是不是证明了某个命题
  ```

- 构造自我指涉命题

  哥德尔构造出一个特殊命题 `G`：

  ```
  G：命题 G 本身不可被证明
  ```

  更精确地说：

  ```
  编号为 g 的命题不可被证明
  ```

  其中 `g` 正好是命题 `G` 自己的哥德尔编号。

- 分析命题 G

  如果 `G` 可以被证明，那么系统证明了：

  ```
  G 不可被证明
  ```

  这会导致矛盾。

  如果系统是无矛盾的，那么 `G` 就不能被证明。

- 得出第一不完备定理

  如果系统无矛盾，那么 `G` 不可被证明。

  但 `G` 的内容正是：

  ```
  G 不可被证明
  ```

  所以 `G` 是真的，却无法在系统内部被证明。

- 得出核心结论

  因此，任何足够强且无矛盾的形式系统中，都存在：

  ```
  真的命题
  但无法被证明
  ```

- 与图灵停机问题的关系

  图灵停机问题问的是：

  ```
  是否存在一个万能程序，可以判断任意程序是否会停机？
  ```

  图灵证明答案是否定的。图灵停机问题说明：计算中存在无法由算法解决的问题

### 生命游戏

康威生命游戏：只用极少数规则，就能在格子世界中产生令人惊讶的复杂图案，展示简单规则如何涌现复杂行为。

生命游戏不是传统意义上的游戏，而是一种二维格子上的数学模型。每个格子只有两种状态：生或死。下一时刻的状态由周围 8 个邻居决定。

看似机械的规则，经过多轮迭代后却能产生稳定结构、振荡结构、移动结构，甚至近似计算能力。这让人看到复杂性科学中的一个核心思想：复杂不一定来自复杂规则，也可能来自简单规则的反复作用。

| 当前状态 | 邻居数量 | 下一状态   |
| -------- | -------: | ---------- |
| 活细胞   |   少于 2 | 死亡：孤独 |
| 活细胞   |   2 或 3 | 存活       |
| 活细胞   |   多于 3 | 死亡：拥挤 |
| 死细胞   |   正好 3 | 诞生       |

- 简单局部规则可以涌现复杂整体行为。

### 无理数

从自然数到整数、有理数、无理数、实数，人类不断发明新的数来填补旧数系无法表达的空白。

人类先有自然数，用来计数；后来为了表示欠债或方向，引入负数；为了表示分割，引入分数；但当人们试图表示正方形对角线长度时，发现有些长度无法写成两个整数之比，例如 \(\sqrt{2}\)。这就是无理数登场的时刻。

无理数的意思是不能写成两个整数之比

> [!NOTE]
>
> 经典证明：\(\sqrt{2}\) 不是有理数
>
> 假设：
>
> $$
> \sqrt{2}=\frac{p}{q}
> $$
>
> 其中 \(p,q\) 没有公因数。平方得：
>
> $$
> p^2=2q^2
> $$
>
> 所以 \(p^2\) 是偶数，进而 \(p\) 是偶数。设 \(p=2k\)，代回得：
>
> $$
> 4k^2=2q^2 \Rightarrow q^2=2k^2
> $$
>
> 所以 \(q\) 也是偶数。这与 \(p,q\) 没有公因数矛盾，因此 \(\sqrt{2}\) 不是有理数。

### 在复平面上野餐

把复数从“虚构的数”变成平面上的几何对象：复数不仅能表示位置，还能用乘法表达旋转与缩放。

> [!TIP]
>
> 人们总是忽视代数，只有当其与几何（人的直观）联系起来的时候，才会发现其用处

复数最初看起来像数学中的怪物，因为它引入了 \(i\)，满足：

$$
i^2=-1
$$

但一旦把复数放到平面上，它就变得直观起来。横轴表示实部，纵轴表示虚部，一个复数 \(a+bi\) 就是平面上的一个点或向量。

更精彩的是复数乘法的几何意义：乘以一个复数，往往相当于对平面上的点进行缩放和旋转。尤其是乘以 \(i\)，相当于逆时针旋转 90 度

### 黎曼猜想

以素数分布为入口，介绍黎曼猜想：素数看似无规律，却可能隐藏在黎曼 ζ 函数零点的深层结构中

素数是只能被 1 和自身整除的大于 1 的整数，例如 2、3、5、7、11。它们像整数世界的原子，因为每个大于 1 的整数都可以唯一分解为素数乘积。

问题是：素数出现在哪里？它们没有简单的通项公式，却又不是完全混乱。数学家发现，素数的整体分布可以被近似描述，而黎曼进一步把它与一个复杂函数联系起来：黎曼 ζ 函数。

黎曼 ζ 函数在某些区域可写为：

$$
\zeta(s)=\sum_{n=1}^{\infty}\frac{1}{n^s}
$$

欧拉乘积揭示它与素数的联系：

$$
\zeta(s)=\prod_{p\ \text{prime}}\frac{1}{1-p^{-s}}
$$

黎曼猜想断言：ζ 函数所有非平凡零点的实部都是 \(1/2\)。

计算机算出来的素数都满足这个关系，但是仍然没有被证明出来
