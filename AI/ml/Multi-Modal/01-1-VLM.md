# VLM Intro

多模态中最主要的两个模态vision-language，视觉语言模型



## Motivation

signle-modality不能很好地理解真实世界



- open-vocabulary detection:检测器不再只识别训练集中固定的类别，而是可以根据文本提示检测新的类别。传统目标检测是 closed-set detection，只能输出固定的类别
- grounding:给模型一张图和一段文字，让模型找出文字中某个短语对应图像里的区域

主要是三个发展脉络

1. **早期视觉语言任务阶段**：主要做 caption、VQA、图文检索。模型通常是 CNN 或 detector 提视觉特征，再和 RNN、Transformer 文本特征融合。
2. **图文对齐阶段**：代表是 CLIP。它用大规模图文对训练，把图像和文本映射到同一个语义空间，所以可以做 zero-shot classification 和 open-vocabulary 任务。VLM survey 也把 CLIP 看作后续大规模 VLM 的重要基础之一。
3. **生成式 VLM 阶段**：代表有 BLIP、Flamingo、LLaVA、GPT-4V、Qwen-VL 等。模型不只是匹配图文，而是能围绕图像进行问答、解释、推理和多轮对话。近年的 VLM 趋势是用强大的 LLM 作为语言主干，再接入视觉编码器和 adapter

| 时间         | Milestone                     | 一句话总结                                                   |
| ------------ | ----------------------------- | ------------------------------------------------------------ |
| 2019         | **ViLBERT / LXMERT / UNITER** | 早期 VLM 把图像区域特征和文本 token 送入 cross-modal Transformer，让模型从单任务 VQA / captioning 走向可迁移的图文预训练。 |
| 2021         | **CLIP**                      | CLIP 把 VLM 的核心从“图文融合做任务”变成“大规模 image-text contrastive learning”，从而获得 zero-shot 分类和检索能力。 |
| 2021         | **ALBEF**                     | ALBEF 提出 align before fuse，先做图文对齐再做融合，缓解视觉 token 和文本 token 直接融合时语义不对齐的问题。 |
| 2022         | **BLIP**                      | BLIP 把图文理解和图文生成统一起来，并用 captioner 和 filter 清洗 noisy web data，让数据质量成为 VLM 性能的重要因素。 |
| 2022         | **Flamingo**                  | Flamingo 把视觉模型和语言模型接起来，支持图文交错输入，并展示了 multimodal in-context learning。 |
| 2022         | **PaLI**                      | PaLI 证明了视觉模型和语言模型可以一起 scale，并把 VLM 扩展到多语言、多任务的大模型范式。 |
| 2023         | **BLIP-2**                    | BLIP-2 冻结 image encoder 和 LLM，只训练轻量 Q-Former 来连接两种模型，大幅降低了构建 VLM 的训练成本。 |
| 2023         | **MiniGPT-4**                 | MiniGPT-4 进一步说明，只要把视觉特征对齐到强 LLM，模型就能出现更强的图像描述、视觉对话和简单推理能力。 |
| 2023         | **LLaVA**                     | LLaVA 把 GPT 生成的 multimodal instruction data 用于训练 VLM，使 VLM 从“做固定任务”转向“像聊天助手一样按指令看图回答”。 |
| 2023         | **InstructBLIP**              | InstructBLIP 系统化研究 visual instruction tuning，把大量公开视觉任务改写成指令格式，让模型泛化到未见任务。 |
| 2023         | **SigLIP**                    | SigLIP 把 CLIP 的 softmax contrastive loss 换成 pairwise sigmoid loss，使 image-text pretraining 在 batch size 和训练效率上更灵活。 |
| 2023 到 2024 | **InternVL / Qwen-VL 系列**   | 这一阶段的重点从“能对话”变成“更强视觉 backbone、更高分辨率、更好 OCR、文档理解和 grounding”。 |
| 2024         | **LLaVA-OneVision**           | LLaVA-OneVision 把单图、多图和视频理解统一到一个 open LMM 中，说明图像训练能力可以迁移到视频场景。 |
| 2024         | **Molmo / PixMo**             | Molmo 强调 open weights 和 open data，代表开源 VLM 从“复现闭源能力”走向“数据透明和可复用”。 |
| 2024 到 2025 | **Eagle**                     | Eagle 的主线是 data-centric strategies 和 mixture of encoders，目标是提升通用图文理解、长上下文图像视频推理，以及 embodied 场景能力。 |
| 2025         | **Eagle 2 / Eagle 2.5**       | Eagle 2 更强调 post-training data strategies，Eagle 2.5 更强调 long-context multimodal understanding，适合你重点关注数据配方、视觉 encoder 选择和部署代价。 |
| 2025         | **Rex-Omni**                  | Rex-Omni 把 MLLM 用到检测和 grounding，把框坐标转成离散 token，并用 SFT 和 GRPO 改善定位精度和重复预测问题。 |

**CLIP → BLIP-2 → LLaVA → InstructBLIP → InternVL 或 Qwen-VL → Eagle → Rex-Omni**

## Training



instruction tuning  SFT 是 Supervised Fine-Tuning，也就是监督微调

SFT 的作用主要有三个：

- 让模型学会 instruction following
- 让模型学会回答格式
- 给后续 RL 一个稳定起点

但 SFT 的问题也很明显。它本质上是模仿学习。模型只是在学训练数据中的答案，不一定真的知道哪个答案更优，也不一定能通过试错提升

> SFT到什么程度开始RL了？

RL alignment

只用 SFT 的问题是模型容易停留在模仿阶段。它不会主动探索更好的答案。

只用 GRPO 的问题是模型初期可能输出很乱，reward 信号也很稀疏。DeepSeek-R1-Zero 就展示了纯 RL 可以激发 reasoning，但也出现可读性和语言混杂问题。

所以 SFT + GRPO 的直觉是：

SFT 先把模型带到一个像样的位置，GRPO 再让模型在这个位置上通过 reward 继续提升。
